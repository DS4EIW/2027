# DS4EIW 2027

Website for the 6th International Workshop on Data Science for Equality, Inclusion and Well-being Challenges, co-located with IEEE ICDE 2027 in Copenhagen, Denmark.

**Workshop date:** May 17, 2027 (tentative).

Website: https://ds4eiw.github.io/2027/

## Local preview

This is a static HTML/CSS website. No build step is required.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000/.

## Deployment

GitHub Pages: **Deploy from a branch**, branch **main**, folder **/ (root)**.
